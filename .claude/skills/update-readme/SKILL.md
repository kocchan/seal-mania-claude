# README更新スキル

プロジェクトのREADME.mdを現在の機能に合わせて更新する。

## 実行タイミング

- 新しい機能を追加したとき
- 既存機能を変更したとき
- フォルダ構成が変わったとき

## 更新手順

1. 現在の `config/sightings.json` を確認してテーマ設定を反映
2. `.claude/skills/` 以下のスキルを確認して機能一覧を更新
3. フォルダ構成を確認して構成図を更新
4. `README.md` を更新

## README構成

```markdown
# seal-mania-claude

[プロジェクト概要 - 今後進化していく内容]

## テーマ設定
config/sightings.jsonの説明

## 機能
各スキルの概要

## セットアップ
インストール手順

## フォルダ構成
現在のフォルダ構成図
```

## 注意

- 既存の説明文のトーンを維持する
- 不要な詳細は省き、簡潔に書く
