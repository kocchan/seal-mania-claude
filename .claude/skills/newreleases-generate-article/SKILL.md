# 記事生成スキル

rawデータを元に、競合に負けないクオリティの記事を生成する。

## 実行方法

```bash
claude "/newreleases-generate-article"
```

## 入力

`output/new-releases/raw/{date}/` 内のMarkdownファイル

## 出力

`output/new-releases/drafts/{date}-{slug}.md`

## 競合分析に基づく記事設計

### 競合サイトの特徴

| サイト | 特徴 |
|--------|------|
| ボンボンナビ | 表組み多用、FAQ充実、LINE誘導 |
| カホメモ | 詳細なルール解説、カラーボックス活用 |
| 入荷Now | 速報性重視、アプリ誘導 |

### 差別化ポイント

| 項目 | 競合 | 自社 |
|------|------|------|
| 情報量 | 基本情報のみ | 店舗アクセス・営業時間も |
| 画像 | 公式1枚 | 複数画像・商品画像 |
| 更新頻度 | 1日1回 | 1日3回 |
| 通販リンク | Amazon/楽天のみ | Yahoo!も追加 |

## タスク

### 1. rawデータを読み込む

```bash
ls output/new-releases/raw/{今日の日付}/
```

各ファイルのfrontmatterから以下を取得:
- `deadline`: 締切日時
- `status`: 受付中 のもののみ対象

### 2. 記事構成（競合同等以上）

**目標文字数: 3,500〜5,000文字**

#### タイトル形式

```
【{締切日}締切】{商品名}の抽選販売が{店舗名}で開催！応募方法・対象商品・注意点まとめ
```

例:
- 【5/6本日締切】ちいかわボンボンドロップシールの抽選販売がパーティリコで開催！
- 【5/8締切】サンリオmojiボンボンドロップシールがネットのシール屋さんで抽選販売！

#### 見出し構成

```markdown
# 【{締切日}締切】{商品名}の抽選販売が{店舗名}で開催！

{導入文: 200文字程度。緊急性・限定感を強調}

## 抽選・イベントの概要

{表形式でスケジュールを整理}

## 購入できる商品一覧

{対象商品を表形式でリスト化、画像があれば挿入}

## 応募方法・申込手順

{ステップバイステップで解説}

## 注意点【必読】

### 1. 申込は1人1回まで
### 2. 本人確認が必須
### 3. 代理購入・譲渡について
### 4. 当日フリー販売について
### 5. 遅刻・キャンセルについて

## よくある質問（FAQ）

### Q. 申込期間はいつまで？
### Q. 当選したら必ず買える？
### Q. 購入制限は？
### Q. 当選メールが届かない場合は？

## 抽選に申し込む

{CTA: LivePocketや申込フォームへの直接リンク}

## 店舗情報・アクセス

{住所、最寄り駅、営業時間、地図}

## 抽選に外れた場合の購入方法

{通販リンク: Amazon、楽天、Yahoo!ショッピング}

## まとめ

{締切日を再度強調、行動を促す}
```

### 3. 導入文テンプレート

```markdown
{店舗名}にて、大人気の**{商品名}**の抽選販売が実施されます！

申込締切は**{締切日時}**と迫っています。混雑回避のため事前申込制となっており、当日フリー販売はありません。

今回の対象商品は全{商品数}種類。{商品の魅力を1文で}

本記事では、**申込方法・対象商品・注意点**を詳しく解説します。締切前に必ずチェックしてください！
```

### 4. 表組みテンプレート

#### 抽選スケジュール表

```markdown
| 項目 | 内容 |
|------|------|
| 申込期間 | {開始日時}〜**{終了日時}** |
| 当選発表 | {発表日時} |
| 販売日 | {販売日} |
| 販売時間 | {開始時間}〜{終了時間} |
| 販売形式 | {時間帯指定・◯分交代制など} |

|-----|--------|-------------|

| 2 | {商品2} | {価格2}円 |
```

### 5. 注意点セクション（重要度高）

競合が詳しく書いている部分。ここを充実させることで信頼性UP。

```markdown
## 注意点【必読】

以下のルールを必ず確認してください。**知らずに当日行くとトラブルになる可能性があります。**

### 1. 申込は1人1回まで

重複申込は**すべて無効**となります。家族や友人の分をまとめて申し込むこともできません。

### 2. 本人確認が必須

当日は**顔写真付き身分証明書の原本**が必要です。

**使用可能な身分証:**
- 運転免許証
- マイナンバーカード
- パスポート
- 学生証（顔写真付き）

**使用不可:**
- コピー・スクリーンショット
- 有効期限切れの証明書
- 顔写真のない保険証（単体では不可の場合あり）

申込時の登録情報と身分証の記載が**完全一致**していないと購入できません。旧姓・通称名での登録にご注意ください。

### 3. 代理購入・譲渡について

- 代理購入: **不可**
- 当選権の譲渡: **不可**
- 同伴者: {可/不可}

当選者本人のみが購入できます。

### 4. 当日フリー販売について

{フリー販売の有無}

当選者以外は購入できません。

### 5. 遅刻・キャンセルについて

集合時間に遅れた場合、**いかなる理由があっても販売をお断り**されます。

- 公共交通機関の遅延 → 購入不可
- 体調不良 → 購入不可
- 道に迷った → 購入不可

時間に余裕を持って会場に向かいましょう。
```

### 6. FAQセクション

```markdown
## よくある質問（FAQ）

### Q. 申込期間はいつまで？

**A. {締切日時}** までです。締切を過ぎると申込できません。早めの応募をおすすめします。

### Q. 先着順？抽選？

**A. 抽選です。** 申込期間内であればいつ応募しても当選確率は同じです。締切直前に慌てて申し込む必要はありません。

### Q. 当選したら必ず買える？

**A. 在庫状況によります。** 後半の時間帯では人気商品が品切れになる可能性があります。早い時間帯が有利です。

### Q. 購入制限は？

**A. {購入制限}** です。{詳細}

### Q. 当選メールが届かない場合は？

**A. 迷惑メールフォルダを確認してください。** LivePocketからのメールが迷惑メールに振り分けられることがあります。`@livepocket.jp` を受信許可設定してください。
```

```markdown

抽選に外れてしまった方や、申込を逃してしまった方は、ネット通販でも探してみてください。

転売価格になっている場合もありますが、公式の再販を待つのも一つの手です。

- [Amazonで「{商品名}」を探す](https://www.amazon.co.jp/s?k={URLエンコード商品名})
- [楽天市場で「{商品名}」を探す](https://search.rakuten.co.jp/search/mall/{URLエンコード商品名})
- [Yahoo!ショッピングで「{商品名}」を探す](https://shopping.yahoo.co.jp/search?p={URLエンコード商品名})
```

**今回のポイント:**

- 申込締切: **{締切日時}**

👉 **[今すぐ抽選に申し込む]({申込URL})**

### 9. ファイル保存

出力ファイル名: `output/new-releases/drafts/{date}-{slug}.md`

slug生成ルール:
- 店舗名をローマ字化（例: partyrico-fujimi）
- 商品カテゴリを追加（例: chiikawa）
- ハイフン区切り

例: `2026-05-06-partyrico-fujimi-chiikawa.md`

## 品質チェックリスト

記事生成後、以下を確認:

- [ ] 文字数が3,500文字以上
- [ ] タイトルに締切日が入っている
- [ ] 導入文で緊急性を伝えている
- [ ] スケジュール表がある
- [ ] 商品一覧表がある
- [ ] 注意点が5項目以上ある
- [ ] FAQが4問以上ある
- [ ] 申込URLへのCTAがある
- [ ] 通販リンクがある
- [ ] まとめで締切を再度強調している
