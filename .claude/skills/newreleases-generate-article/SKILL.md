# 記事生成スキル

rawデータを元に、WordPress投稿用の記事を生成してdraftsに保存する。

**このスキルの役割**: `output/new-releases/raw/` → 記事生成 → `output/new-releases/drafts/` に保存

**情報収集は別スキル**: `/newreleases-collect` で実行

## 実行方法

```bash
claude "/newreleases-generate-article"
```

## 入力

`output/new-releases/raw/{date}/` 内のMarkdownファイル

## 出力

`output/new-releases/drafts/{date}-{slug}.md`

## WordPress対応のポイント

### 1. SEO対策

- **タイトル**: 32文字以内、キーワードを前方に配置
- **description**: 120文字以内、検索結果に表示される要約
- **見出し構造**: H2 → H3 の階層を守る（H1はタイトルのみ）

### 2. HTML変換を意識した書き方

WordPressでMarkdown→HTML変換時に崩れないよう:

- 表組みはシンプルに（複雑なセル結合は避ける）
- リスト記号は `-` で統一
- 強調は `**太字**` で統一
- リンクは `[テキスト](URL)` 形式

### 3. ブロックエディタ対応

- 各セクションは明確に区切る（`---` は使わない）
- ボックス装飾は使わない（テーマ依存のため）
- 画像は `![alt](URL)` 形式で

## タスク

### 1. rawデータを読み込む

```bash
ls output/new-releases/raw/{今日の日付}/
```

各ファイルのfrontmatterから以下を確認:
- `deadline`: 締切日時
- `status`: 受付中 のもののみ対象

### 2. 記事を生成

**目標文字数: 3,500〜5,000文字**

#### タイトル形式（32文字以内推奨）

```
【{締切日}締切】{商品名}の抽選販売@{店舗名}
```

例:
- 【5/6締切】ちいかわボンドロ抽選@パーティリコ
- 【5/8締切】サンリオmoji抽選@ネットのシール屋さん

#### 見出し構成

```markdown
# 【{締切日}締切】{商品名}の抽選販売が{店舗名}で開催！

{導入文: 200文字程度}

## 抽選・イベントの概要

## 購入できる商品一覧

## 応募方法・申込手順

## 注意点

### 申込は1人1回まで
### 本人確認が必須
### 代理購入・譲渡について
### 当日フリー販売について
### 遅刻・キャンセルについて

## よくある質問（FAQ）

## 抽選に申し込む

## 店舗情報・アクセス

## 抽選に外れた場合の購入方法

## まとめ
```

### 4. 導入文テンプレート

```markdown

申込締切は**{締切日時}**と迫っています。混雑回避のため事前申込制となっており、当日フリー販売はありません。

本記事では、**申込方法・対象商品・注意点**を詳しく解説します。締切前に必ずチェックしてください！
```

### 6. 注意点セクション（重要）

```markdown
## 注意点

以下のルールを必ず確認してください。知らずに当日行くとトラブルになる可能性があります。

### 申込は1人1回まで

重複申込は**すべて無効**となります。家族や友人の分をまとめて申し込むこともできません。

### 本人確認が必須

当日は**顔写真付き身分証明書の原本**が必要です。

**使用可能な身分証:**
- 運転免許証
- マイナンバーカード
- パスポート
- 学生証（顔写真付き）

**使用不可:**
- コピー・スクリーンショット
- 有効期限切れの証明書

### 代理購入・譲渡について

- 代理購入: **不可**
- 当選権の譲渡: **不可**

当選者本人のみが購入できます。

### 当日フリー販売について

当日フリー販売は**ありません**。当選者以外は購入できません。

### 遅刻・キャンセルについて

集合時間に遅れた場合、**いかなる理由があっても販売をお断り**されます。

- 公共交通機関の遅延 → 購入不可
- 体調不良 → 購入不可

時間に余裕を持って会場に向かいましょう。
```

### 7. FAQセクション

```markdown
## よくある質問（FAQ）

### Q. 申込期間はいつまで？

A. **{締切日時}** までです。締切を過ぎると申込できません。

### Q. 先着順？抽選？

A. **抽選**です。申込期間内であればいつ応募しても当選確率は同じです。

### Q. 当選したら必ず買える？

A. 在庫状況によります。後半の時間帯では品切れの可能性があります。

### Q. 購入制限は？

A. **{購入制限}** です。

### Q. 当選メールが届かない場合は？

A. 迷惑メールフォルダを確認してください。`@livepocket.jp` を受信許可設定してください。
```

### 10. ファイル保存

出力: `output/new-releases/drafts/{date}-{slug}.md`

slug生成ルール:
- 店舗名をローマ字化: `partyrico-fujimi`
- 商品カテゴリを追加: `chiikawa`
- 日付を追加: `20260506`
- ハイフン区切り

例: `2026-05-06-partyrico-fujimi-chiikawa.md`

### 11. git commit & push

```bash
git add output/new-releases/drafts/
git commit -m "chore: 記事を生成 [skip ci]"
git push
```

## 品質チェックリスト

記事生成後、以下を確認:

- [ ] 文字数が3,500文字以上
- [ ] タイトルに締切日が入っている
- [ ] タイトルが32文字以内
- [ ] descriptionが120文字以内
- [ ] 導入文で緊急性を伝えている
- [ ] スケジュール表がある
- [ ] 商品一覧表がある
- [ ] 注意点が5項目ある
- [ ] FAQが5問ある
- [ ] 申込URLへのCTAがある
- [ ] 通販リンクが3つある（Amazon/楽天/Yahoo!）
- [ ] まとめで締切を再度強調している
- [ ] Markdown記法がWordPress互換
