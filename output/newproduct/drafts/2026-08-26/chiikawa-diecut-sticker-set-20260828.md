# 【8/28発売】ダイカットステッカー - ちいかわ新作

『ちいかわ』の新商品として、ちいかわたちのお顔をあしらった「アニメちいかわ ダイカットステッカーセット」が2026年8月28日より順次発売される。1セット4枚入りで全64種というボリュームが用意されており、コレクター心をくすぐる仕上がりだ。同時に「ちよがみ」やアニメ第33話まで収録した「ストーリーブック」、飛び出す仕掛けが楽しい「とびだす アニメちいかわ」も登場し、シール好き・ちいかわファンともに見逃せないラインナップとなっている。

## 商品概要

「アニメちいかわ ダイカットステッカーセット」は、キャラクターの輪郭に沿ってカットされたダイカット仕様のステッカーセット。ちいかわ、ハチワレ、うさぎといった人気キャラクターたちの、さまざまな表情やポーズがデザインされている。1セットあたり4枚入りで、全体では64種類が展開されるため、どの組み合わせが手に入るか分からないコレクション性も魅力の一つだ。全国のカードダス自販機のほか、アニメショップ、家電量販店などで取り扱われる予定で、シールコレクターにとって新たな定番アイテムになりそうだ。

同時発売の「ちよがみ」は、ちいかわ・ハチワレ・うさぎがプリントされた折り紙で、デザイン2種・計12枚入り。すでに全国の100円均一店などで発売中となっている。書籍系では、アニメ第1話から第31〜33話「穴に落ちた」までを収めた「アニメ ストーリーブック」が9月10日発売、ページをめくるとキャラクターが飛び出す立体仕掛けの「とびだす アニメちいかわ」が10月16日発売と、順次ラインナップが拡充されていく。

## 商品の魅力・見どころ

今回のダイカットステッカーセットの一番の魅力は、なんといっても全64種という圧倒的なボリュームだ。ちいかわ、ハチワレ、うさぎなど個性豊かなキャラクターたちの多彩な表情が一つひとつ丁寧にダイカットされており、ノートやスマホケース、水筒などさまざまなアイテムに貼って楽しめる。1セット4枚入りというランダム性のある販売形式は、集める過程そのものが楽しみになるコレクター向けの仕様だ。

『ちいかわ』は2020年の連載開始からSNSを中心に人気を博し、「日本キャラクター大賞グランプリ」では殿堂入りを果たした国民的キャラクター。アニメの見逃し配信は総再生回数5億回を突破し、現在公開中の映画『映画ちいかわ 人魚の島のひみつ』は公開30日間で興行収入100億円を突破するなど、勢いはとどまるところを知らない。そんな旬のタイミングでの新作ステッカー展開だけに、店頭では早期の品薄も予想される。

書籍系の新商品もあわせて要チェックだ。「アニメ ストーリーブック」はアニメの名場面を手元でじっくり楽しめる一冊で、8月25日から全国書店・Amazon・楽天ブックスなどで予約が始まっている。「とびだす アニメちいかわ」は立体仕掛けのポップアップ絵本で、子どもから大人まで楽しめる仕上がりとなっており、ステッカーとあわせてグッズコレクションの幅を広げてくれそうだ。

## どこで買える？

「ダイカットステッカーセット」は全国のカードダス自販機のほか、アニメショップ、家電量販店などで発売される。「ちよがみ」は100円均一店などで発売中。書籍系の商品は全国の書店やAmazon、楽天ブックスなどのオンライン書店でも取り扱われる予定だ。
