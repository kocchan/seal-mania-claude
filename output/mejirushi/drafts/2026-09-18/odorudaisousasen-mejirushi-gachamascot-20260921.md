# 【9月下旬発売】踊る大捜査線 めじるしガチャマスコット

映画シリーズ最新作『踊る大捜査線 N.E.W.』とコラボした、めじるしガチャマスコットが登場します。タカラトミーアーツから2026年9月下旬に発売予定のこのガチャは、劇中に登場する名物アイテムやキャラクターを立体化したユニークなラインナップ。バンダイの「めじるしアクセサリー」とはひと味違う、遊び心たっぷりの全6種です。

## 商品概要

「めじるしガチャマスコット」は、傘やペットボトルなどに取り付けられるリングパーツ付きのマスコットチャームです。今回は『踊る大捜査線』シリーズとのコラボレーションとして、劇中のキャラクターやおなじみのアイテムが立体化されました。中でも影絵の立体が入ったクリアケースは、映画のワンシーンを思わせる演出になっています。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| シルエット立体1 | 影絵の立体が入ったクリアケース仕様 |
| シルエット立体2 | 別デザインの影絵入りクリアケース |
| シルエット立体3 | もう一種の影絵入りクリアケース |
| 台場レインボー最中 | 劇中でおなじみのご当地スイーツをモチーフ化 |
| 湾岸君 | シリーズファンにはおなじみの人気キャラクター |
| カエル急便 | 作品を象徴する小道具のひとつを立体化 |

3種のクリアケースはどのシルエットが入っているか届いてからのお楽しみという、ガチャならではのワクワク感も魅力です。

## 発売情報

| 項目 | 内容 |
|------|------|
| 発売日 | 2026年9月下旬 |
| 販売形態 | ガチャガチャ（1回400円） |
| 価格 | 400円（税込） |
| 設置場所 | 全国のガチャガチャ設置店舗（予定） |

サイズは本体約35～45mm、材質は本体がPVC・ABS、リングパーツはシリコーンゴムです。

## ここがかわいい！見どころ

見どころは、なんといっても「踊る大捜査線」らしいユーモアと遊び心が詰まったラインナップです。台場レインボー最中や湾岸君など、シリーズを見てきたファンならクスッと笑ってしまうようなモチーフが立体化されており、思わずコンプリートしたくなる仕上がりです。影絵入りのクリアケースは、映画のワンシーンを思い出させる演出になっており、ドラマ・映画ファンのコレクション欲を刺激します。

## どこで回せる？買える？

全国のガチャガチャ設置店舗での展開が予定されており、ショッピングモールやアミューズメント施設のガチャガチャコーナーで見つけることができます。タカラトミーアーツの商品はコンビニやゲームセンター内のガチャコーナーに置かれることも多いため、普段利用する施設のガチャ売り場を覗いてみるのもおすすめです。映画公開時期に合わせて、映画館のロビーやシネコンの物販コーナーに設置されるケースもあるため、鑑賞の際にはあわせてチェックしてみましょう。

## 大人世代にも刺さるコラボアイテム

『踊る大捜査線』シリーズは1990年代から続く人気ドラマ・映画シリーズで、幅広い世代のファンに愛され続けています。今回のめじるしガチャマスコットは、そんな長年のファンにとって懐かしさとユーモアを同時に味わえるアイテムです。お仕事バッグやビジネスバッグにさりげなく付ければ、大人世代ならではのさりげないファン活動としても楽しめます。プレゼントとしても喜ばれる、遊び心のある一品です。
