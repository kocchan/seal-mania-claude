# 【9/28発売】Among Us めじるしアクセサリー

世界中で人気のオンライン人狼アクションゲーム『Among Us（アマング アス）』が、カラフルなめじるしアクセサリーになって登場します！バンダイのガシャポンより2026年9月28日11時から販売開始。おなじみのカラフルなクルーメイトに加え、半透明仕上げのゴーストも収録した全8種のラインナップです。

## 商品概要

「Among Us めじるしアクセサリー」は、世界的に人気のオンライン人狼アクションゲーム『Among Us』のキャラクターをモチーフにしためじるしアクセサリーです。ゲームの象徴でもあるカラフルな宇宙服姿のクルーメイトを、レッド・ブルー・グリーン・イエロー・ブラック・ホワイト・ピンク・オレンジの8色でラインナップ。傘やバッグ、ペットボトルなどに取り付けて、自分の持ち物の目印として使えます。

特にゲーム内で「裏切り者」に倒されてしまった状態を表す「ゴースト」は半透明仕様で再現されており、通常のクルーメイトとはひと味違う特別感があります。

## ラインナップ

カラフルなクルーメイト＋ゴースト仕様を含む全8種です。

| 種類 | ポイント |
|------|----------|
| レッド | 定番カラーの一体。まず手に入れたい一色 |
| ブルー | クールな印象のカラーリング |
| グリーン | 爽やかで見つけやすい色合い |
| イエロー | 明るく目立つポップなカラー |
| ブラック | シックで大人っぽい雰囲気 |
| ホワイト | どんな持ち物にも合わせやすい定番色 |
| ピンク | かわいらしさが際立つ人気カラー |
| オレンジ | 元気なイメージのビタミンカラー |

※各カラーとも、ゲーム内で倒された状態を表す半透明の「ゴースト」仕様で収録されています。

## ここがかわいい！見どころ

一番の見どころは、ゲームの世界観をそのまま閉じ込めたカラフルなラインナップ。8色全部を集めれば、まるでゲーム内のクルーメイト全員集合のような賑やかさになります。さらに半透明のゴースト仕様が加わることで、単色のシルエットチャームにはない透明感のある特別な仕上がりを楽しめるのもポイントです。

友達や家族と「推し色」を持ち寄って集めるのはもちろん、複数のカラーをまとめてバッグや傘につければ、それだけで『Among Us』ファンだと分かる目印に。ゲーム好きの間で「あの色が出た！」と盛り上がれる、コレクション欲をくすぐるアイテムです。
