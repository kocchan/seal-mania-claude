# 【8/3発売】ヒロアカ×マリオンクレープ めじるしキーホルダー

大人気アニメ『僕のヒーローアカデミア』と全国の人気クレープ専門店「マリオンクレープ」のコラボレーションが、2026年8月3日（月）からスタートします！パティシエ姿に変身した緑谷出久たちのオリジナルグッズの中に、「トレーディングめじるしキーホルダーミニキャラver．」が初登場。全国32店舗とオンラインで展開される、見逃せないコラボ企画です。

## 商品概要

今回のコラボは、パティシエ姿でクレープを提供する緑谷出久たち6人の描き下ろしビジュアルが目印。オリジナルグッズとして「アクリルフィギュアスタンドパティシエver．」「ポラショットコレクションパティシエver．」に加えて、「トレーディングめじるしキーホルダーミニキャラver．」がラインナップされます。めじるしキーホルダーは、傘やバッグなど普段使いのアイテムに取り付けられる、持ち物の目印にぴったりなアイテムです。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| トレーディングめじるしキーホルダー ミニキャラver． | パティシエ姿のミニキャラをデザイン。トレーディング形式でどれが届くかはお楽しみ |
| アクリルフィギュアスタンド パティシエver． | 卓上に飾れる描き下ろしアクリルスタンド |
| ポラショットコレクション パティシエver． | まるでチェキ写真のようなカード仕立てのコレクションアイテム |
| ノベルティコースター（全6種） | クレープ1点注文ごとにランダムで1枚もらえる特典 |

## 発売情報

| 項目 | 内容 |
|------|------|
| 開催期間 | 2026年8月3日（月）〜（メニュー・特典は8月18日〈火〉から一部切り替え） |
| 販売形態 | 店頭購入＋オンライン販売 |
| 価格 | 関連グッズ税込2,000円ごとに特典をランダムで1枚プレゼント（各グッズ単体の価格は店舗・オンラインストアにて要確認） |
| 設置場所 | 全国の「マリオンクレープ」32店舗＋オンラインストア |

※8月3日（月）からは購入特典「デスクカード」（全6種）、8月18日（火）からは「ネームカード」（全6種）がランダムで1枚もらえます。

## ここがかわいい！見どころ

### パティシエ姿のデクたちがまさかのグッズ化

普段のヒーロースーツ姿とは一味違う、エプロン姿・コック帽姿の「パティシエ姿」のキャラクターたちが描き下ろしで登場。ギャップ萌え必至のかわいさで、コレクション欲をくすぐられます。

### トレーディング形式でどのキャラが届くかはお楽しみ

「トレーディングめじるしキーホルダーミニキャラver．」は、購入時にどのキャラクターが手に入るかわからないトレーディング形式。推しキャラを求めて何度も挑戦したくなる、ワクワク感のある展開です。

### 傘やバッグの“めじるし”として大活躍

キーホルダーサイズなので、通学バッグや傘の持ち手などに取り付けて、自分の持ち物の目印として使うのにぴったり。友達とキャラ違いを見せ合うのも楽しい時間になりそうです。

## どこで回せる？買える？

全国の「マリオンクレープ」32店舗にて、2026年8月3日（月）から順次展開されます。お店に行けない人でも、オンラインストアでの購入が可能なのがうれしいポイント。コラボクレープは1点注文ごとにノベルティコースターがランダムでもらえるので、クレープを楽しみながらグッズも集められます。売り切れが心配な人は、開催初日〜早めのタイミングでのチェックがおすすめです。
