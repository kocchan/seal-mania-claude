# 【9月第5週発売】仮面ライダーシリーズ めじるしアクセサリー5

歴代「仮面ライダーシリーズ」の名アイテムをチャーム化しためじるしアクセサリーに、待望の第5弾が登場します！バンダイのガシャポンより2026年9月第5週発売予定で、ライドエグズやハイパーゼクターなど、シリーズを彩ってきた変身アイテムを再現した全10種のラインナップです。

## 商品概要

「仮面ライダーシリーズ めじるしアクセサリー5」は、バンダイ ベンダー事業部が展開するガシャポン（カプセルトイ）シリーズです。仮面ライダーたちが変身の際に使用してきたベルトのバックルやメモリ、変身音叉などのアイテムを、そのままミニチュアチャームとして立体化しています。

シリーズ第5弾となる今回は、ライドエグズやハイパーゼクターといった人気アイテムに加え、ゴチポッド・闇菓子・ブーストバックル・マグナムバックルなど、幅広い作品から集められた10種類がラインナップ。特撮ファンなら「あの変身アイテムだ！」と一目で分かるラインナップです。

## ラインナップ

歴代シリーズの変身アイテムをモチーフにした全10種です。

| 種類 | ポイント |
|------|----------|
| ライドエグズ1 | 人気の変身アイテムをそのままチャーム化 |
| ライドエグズ4 | 別バリエーションもしっかり収録 |
| ゴチポッド | 個性的なフォルムが目を引くアイテム |
| 闇菓子 | ユニークな名称とデザインが特徴 |
| ブーストバックル | ベルトタイプの変身アイテムを再現 |
| マグナムバックル | こちらもベルトタイプの人気アイテム |
| ロケットスイッチ | スイッチ型のギミックアイテムをチャーム化 |
| エクストリームメモリ | メモリタイプの変身アイテム |
| ハイパーゼクター | シリーズを代表する人気アイテムのひとつ |
| 変身音叉・音角 | 音で変身するタイプのユニークなアイテム |

## ここがかわいい！見どころ

見どころは、歴代シリーズの変身アイテムを横断的に集めたラインナップの豊富さ。ベルトのバックルやメモリ、音叉タイプまで、形状もギミックもさまざまなアイテムがミニチュアチャームとして再現されているので、並べて眺めるだけでも仮面ライダーシリーズの奥深さを感じられます。

チャームとして重ねづけできる仕様なので、複数のアイテムをまとめてバッグや傘につければ、自分だけの「変身アイテムコレクション」に。ペットボトルの目印としても使いやすく、特撮好きのお子さんはもちろん、大人のコレクターにも人気が集まりそうなラインナップです。

## どこで回せる？買える？

全国のガシャポンコーナーに順次設置される予定です。ショッピングモールやアミューズメント施設、家電量販店の一角など、設置場所は多岐にわたるため、バンダイ公式の「ガシャポンオフィシャルサイト」内にある設置店検索機能を使って、お近くの取扱店をチェックしてみてください。シリーズ人気商品のため、発売直後は品薄になることもあるので、こまめな確認がおすすめです。
