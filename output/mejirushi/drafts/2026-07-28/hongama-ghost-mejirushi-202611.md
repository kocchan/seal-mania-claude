# 【11月発売】HONGAMA ゴースト めじるしアクリルチャーム

シュールでユーモアたっぷりのイラストが人気のHONGAMAさんによる、初のめじるしアクリルチャームが登場します！ 人気のLINEスタンプキャラクター「GHOST」をモチーフに、さまざまな表情・ポーズの全20種がラインナップ。カプセルトイ専門店KENELE STANDをはじめ、全国5ブランドの店舗で連動展開される話題の新作です。

## 商品概要

「めじるしアクリルチャーム」は、傘やバッグ、水筒などの持ち物に取り付けられる小さなアクリル製チャームです。持ち物の目印になるだけでなく、お気に入りのイラストやキャラクターを日常に取り入れられるアイテムとして人気を集めています。

今回登場する「HONGAMA ゴースト アクリルチャーム」は、イラストレーター・HONGAMAさんのアイコン的キャラクター「GHOST」のLINEスタンプをモチーフにしたグッズ。さまざまな表情やポーズで気持ちを伝えるゴーストたちの魅力が、そのままアクリルチャームに落とし込まれています。HONGAMAさん初のめじるしグッズという点も注目ポイントです。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| GHOST（各種表情） | LINEスタンプでおなじみのシュールな表情バリエーション |
| 全20種 | ケンエレファント系列5ブランドで各4種ずつ展開 |

各店舗で異なる4種類が展開されるため、全店舗を巡ってコンプリートを目指す仕様になっています。

## 発売情報

| 項目 | 内容 |
|------|------|
| 発売日 | 2026年11月中 |
| 販売形態 | カプセルトイ（1回300円・税込） |
| 価格 | 300円（税込） |
| 種類 | 全20種（5ブランド×各4種） |
| 設置場所 | KENELE STAND、ケンエレブンシツ、KENELE STORE、#C-pla、gashacoco、ガチャガチャの森、ドリームカプセル |

※予約はケンエレファント公式オンラインストア「KENELE STORE」で受付中です。店舗によって展開される4種の組み合わせが異なります。

## ここがかわいい！見どころ

一番の見どころは、HONGAMAさんならではのシュールでクセになる表情バリエーションです。ただかわいいだけでなく、思わずクスッと笑ってしまうようなユーモラスな「GHOST」の表情が、アクリルチャームという新しい形でぎゅっと詰め込まれています。

また、5ブランド連動で全20種類という規模の大きさも魅力。1店舗だけでは揃わない仕様になっているため、いろいろなお店を巡りながらコレクションする楽しさも味わえます。バッグや水筒、スマホストラップなど、日常のあちこちに取り付けて「推しゴースト」を持ち歩けます。

## どこで回せる？買える？

KENELE STANDの直営店舗をはじめ、ケンエレブンシツ、#C-pla（シープラ）、gashacoco（ガシャココ）、ガチャガチャの森、ドリームカプセルの各店舗で2026年11月より順次展開予定です。

事前に確実に手に入れたい場合は、ケンエレファント公式オンラインストア「KENELE STORE」での予約がおすすめ。KENELE STOREではケンエレスタンドと同デザインの4種類を取り扱う予定です。
