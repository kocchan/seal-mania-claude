# 【12月発売】ジュエリーヌ めじるしコレクション新作

宝石のようにキラキラ輝くワンちゃんチャームが登場！ブライトリンクのカプセルトイ「ジュエリーヌ めじるしコレクション」が、2026年12月中旬より全国のカプセル自販機で順次発売されます。犬種と宝石を掛け合わせた全5種のラインナップを紹介します。

## 商品概要

「ジュエリーヌ めじるしコレクション」は、「最高にクレイジーなモノづくり」をコンセプトに掲げるブライトリンクが手がけるカプセルトイシリーズ。宝石のようにカットされた透明ボディのワンちゃんを立体化しためじるしチャームで、犬種と宝石の名前を組み合わせた全5種がラインナップします。

コンセプトは「猫が液体なら、犬はカチカチになるしかないワン」。やわらかく形を変える猫に対して、犬はカチカチの結晶になるしかない――というユニークな言葉遊びから生まれたシリーズです。丸みのあるフォルムに細かなカット面が刻まれ、光を受けると角度によって表情が変わる仕上がりになっています。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| ダイヤモンド ポメ | ポメラニアンモチーフ、クリアなダイヤモンドカット |
| パール ビション | ビションフリーゼモチーフ、乳白色のパール調 |
| シトリン シバ | 柴犬モチーフ、淡いイエローのシトリン調 |
| トパーズ プードル | プードルモチーフ、深みのあるブラウンのトパーズ調 |
| クリスタル ダックス | ダックスフンドモチーフ、赤みを帯びたクリスタル調 |

全5種、いずれも1回300円（税込）。ポメラニアンは丸い球体に近いフォルム、ダックスフンドは横に長いフォルムと、犬種ごとにシルエットが作り分けられているのもポイントです。

## ここがかわいい！見どころ

一番の魅力は、宝石のようなカット面が光を受けてキラキラと表情を変えるところ。ダイヤモンド・パール・シトリン・トパーズ・クリスタルと、それぞれの犬種にぴったりな宝石カラーが割り当てられていて、並べて飾るだけでも華やかです。

各アイテムにはカニカン（留め具）とリングが付いているので、バッグやポーチ、傘の持ち手などに取り付けて“めじるし”として活用できます。同じデザインのグッズを持つお友だち同士でも、色違いのワンちゃんチャームを付けておけば一目で見分けがつくのも嬉しいポイントです。

犬派さんはもちろん、宝石モチーフのキラキラアイテムが好きな人にもおすすめできるラインナップ。全5種をコンプリートして、推しの犬種＆宝石カラーを見つける楽しみ方もできそうです。

## どこで回せる？買える？

2026年12月中旬より、全国のカプセル自販機にて順次販売される予定です。設置店舗は個別に案内されていないため、近隣のガシャポンコーナーやショッピングモールのカプセルトイ売り場をこまめにチェックするのがおすすめ。取り扱い状況は各店舗の情報もあわせて確認してください。
