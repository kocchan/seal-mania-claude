# 【10月発売】PLAVE めじるしアクセサリー MMMM着ぐるみ

2023年3月に韓国でデビューしたK-POPバーチャルアイドルグループ「PLAVE（プレイブ）」のめじるしアクセサリーが、バンダイ ガシャポンから登場します！公式キャラクター「MMMM（ムメミム）」の着ぐるみをまとったメンバーたちを、かわいらしく立体化。ファンなら見逃せない全5種のラインナップです。

## 商品概要

「PLAVE めじるしアクセサリー」は、PLAVEの公式マスコットキャラクターであるMMMM（ムメミム）の着ぐるみを着たメンバーの姿をモチーフにしためじるしアクセサリーです。メンバーそれぞれのカラーや個性を感じられるデザインに加え、着ぐるみ姿ならではの特別感も見どころ。傘やバッグ、ペットボトルなどに取り付けて、持ち物を「推し」の目印にできます。

2026年10月発売予定（発売日未定）で、価格は1回400円（税込）。全5種のラインナップで、YEJUN・NOAH・BAMBY・EUNHO・HAMINと、PLAVEの人気メンバー全員がしっかり揃っています。

## ラインナップ

MMMM着ぐるみ姿で立体化されたメンバー全5種です。

| 種類 | ポイント |
|------|----------|
| YEJUN（イェジュン） | PLAVEのリーダー。イルカを思わせる爽やかなブルーカラーが目印 |
| NOAH（ノア） | “姫担当”として親しまれる存在。特徴的な金髪をしっかり再現 |
| BAMBY（バンビ） | トレードマークの大きな目とピンクの髪がキュートに再現 |
| EUNHO（ウノ） | メインラッパー担当。クールなビジュアルが魅力 |
| HAMIN（ハミン） | PLAVEの末っ子。デフォルメされた愛嬌たっぷりの姿が特徴 |

## ここがかわいい！見どころ

一番の見どころは、PLAVEのシンボルであるMMMM着ぐるみ姿でメンバーを再現している点。普段のパフォーマンス姿とはひと味違う、ふわふわとした癒し系のビジュアルになっているのがたまりません。メンバーカラーがしっかり反映されているので、「推し」のカラーを目印にコレクションする楽しみ方もできます。

ピクセルの集合体でできたMMMMのモチーフを丁寧に再現しつつ、YEJUNの爽やかなブルー、NOAHの金髪、BAMBYのピンクなど、メンバーごとの個性がひと目で分かるデザインになっているのもポイント。SNS上でも「絶対欲しい」「めちゃくちゃかわいい」といった反響が寄せられており、発売前から注目度の高いアイテムです。

## どこで回せる？買える？

まずは2026年9月26日（土）から、『2026 PLAVE World Tour [KEEP IT MANIC] in Japan』の公演会場近隣3店舗にて先行販売がスタート。その後、2026年10月に全国のガシャポンコーナーへ順次展開される予定です。設置店舗の詳細は、バンダイ公式の「ガシャポンオフィシャルサイト」内の設置店検索機能で確認できます。ライブ会場での先行販売は数量限定になりやすいため、参戦予定の方は早めのチェックがおすすめです。

海外のK-POPグループのガシャポン化は珍しく、日本国内のファンにとっては貴重なグッズ展開。SNSでの反響の大きさからも分かる通り、発売後は入手が難しくなる可能性があります。全国展開を待てない方は、まずライブ会場での先行販売を狙うのもひとつの手です。
