# 【9/25予約開始】牧場物語 歴代ウシさん めじるしアクセサリー

大人気シリーズ『牧場物語』から、歴代の「ウシさん」だけにスポットを当ためじるしアクセサリーが登場しました！バンダイのガシャポンオンラインにて2026年9月25日17時より予約受付がスタート。1996年のドット絵から2025年のアニメ調デザインまで、全6種のウシさんが勢ぞろいする、シリーズファン必見のアイテムです。

## 商品概要

「牧場物語　歴代ウシさん　めじるしアクセサリー」は、農業＆牧場シミュレーションゲーム『牧場物語』シリーズに登場してきたウシさんたちをモチーフにしためじるしアクセサリーです。1996年の初代作品からスタートし、2025年の最新作まで、時代ごとに変化してきたウシさんのグラフィックをそのままチャームとして立体化しています。

サイズは約3cmとコンパクトで、シリコン製のわっかパーツとカニカンが付属。傘やバッグ、水筒など好きな持ち物にサッと取り付けられ、「これは自分の持ち物！」とひと目で分かる目印として活躍します。長年シリーズを追いかけてきたファンなら、「このドット絵、懐かしい！」「今のウシさんはこんな感じなんだ」と、世代ごとの変化を眺めるだけでも楽しめる商品です。

## ラインナップ

全6種、1996年から2025年までのウシさんが年代順にラインナップされています。

| 種類 | ポイント |
|------|----------|
| ウシさん（1996） | シリーズ第1作の懐かしいドット絵デザイン |
| ウシさん（1999） | 初期シリーズらしい素朴なタッチ |
| ウシさん（2008） | やや丸みを帯びた愛らしいデザインに変化 |
| ウシさん（2012） | カラーリングがより鮮やかに進化 |
| ウシさん（2023） | アニメ調の柔らかい質感で表現 |
| ウシさん（2025） | 最新作らしいリアル寄りの仕上がり |

## ここがかわいい！見どころ

見どころは、なんといっても約30年分のウシさんの「進化」を一気に楽しめる点。ドット絵時代の素朴な佇まいから、最新作の丁寧に描き込まれたビジュアルまで、並べて見比べるだけでシリーズの歴史を感じられます。牧場物語ファンなら「自分が最初にプレイした年代のウシさん」を探して集めるのも楽しみ方のひとつ。

サイズが約3cmと小ぶりなので、複数まとめてバッグにつけてもごちゃつかず、さりげなく持ち物を彩ってくれます。カニカン付きなので、ペンケースの目印やキーホルダーとしても活用しやすいのがうれしいポイントです。

## どこで回せる？買える？

今回はまずガシャポンオンラインでの予約受付からスタートし、2027年1月下旬ごろにお届け予定です。予約数が準備数に達すると受付終了となるため、欲しいデザインがある方は早めのチェックがおすすめ。なお、お届けに先行して全国のカプセル自販機（ガシャポンのデパートやショッピングモールなど）に並ぶ可能性もあるとのことなので、近隣の設置店舗情報もあわせて確認しておくと安心です。
