# 【7月23日受注開始】えばそんめじるしチャーム第2弾

一人芝居のコント動画で人気の動画クリエイター「えばそんEntertainment」から、第2弾となる「めじるしチャーム」の受注販売が2026年7月23日（木）17時にスタートしました。ペンゴロー、タマ、にゃんこマン、ステゴローという、動画でおなじみの人気オリジナルキャラクターたちが、傘やバッグにつけられる可愛いチャームになって登場しています。

## 商品概要

「えばそんEntertainment」は、一人芝居のコント動画で幅広い世代から支持を集める動画クリエイター。YouTuberマネジメント事業を展開する株式会社Carry On（東京都渋谷区）が展開するグッズ企画の第2弾として、今回「めじるしチャーム」が登場しました。ランダムで1種が入った通常版に加え、受注生産限定で全4種を揃えられるコンプリートセットも用意されており、コレクション欲を刺激するラインナップになっています。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| サッカーペンゴロー | サッカーペンギンのキャラクター |
| タマ | ちょっと首の長い犬がモチーフ |
| にゃんこマン | 小石でできたユニークな見た目 |
| ステゴロー | 捨て子の恐竜というちょっと切ない設定 |

ランダム封入の単品に加え、【受注生産限定】で全4種コンプリートセットも販売されています。

## 発売情報

| 項目 | 内容 |
|------|------|
| 受注期間 | **2026年7月23日（木）17:00〜8月5日（水）23:59** |
| 販売形態 | オンラインストア（BASE）でのランダム受注販売／コンプリートセットは受注生産限定 |
| 価格 | ランダムめじるしチャーム：700円（税込）／コンプリートセット：2,800円（税込） |
| お届け時期 | 2026年8月末頃より順次発送予定 |
| 販売元 | 株式会社Carry On（えばそんEntertainment） |

※コンプリートセットは受注期間限定ですが、状況により再販の可能性があります。
※別途送料がかかります。

## ここがかわいい！見どころ

### 動画でおなじみのキャラクターがめじるしに

コント動画でおなじみのオリジナルキャラクターたちが、傘やペットボトル、バッグのファスナーなど、さまざまな持ち物の“めじるし”として楽しめるアイテムになりました。動画ファンならずとも、ゆるいキャラクターデザインに癒されるはず。

### ランダム＆コンプリートの2WAY展開

普段使いなら手軽なランダム封入版、全種類しっかり揃えたい人には受注生産限定のコンプリートセットと、遊び方に合わせて選べるのも嬉しいポイントです。

### 毎日のお出かけがちょっと楽しくなる

お気に入りのキャラクターと一緒に持ち物を彩ることができ、傘やバッグを開けるたびに小さな癒しをもたらしてくれるグッズです。

## どこで回せる？買える？

今回のめじるしチャームは店頭販売やガシャポンではなく、オンラインストア（BASE）での受注販売です。ランダムめじるしチャームとコンプリートセットはそれぞれ専用の商品ページから購入でき、受注期間は2026年7月23日17時から8月5日23時59分まで。期間内に注文すると8月末頃から順次発送されます。
