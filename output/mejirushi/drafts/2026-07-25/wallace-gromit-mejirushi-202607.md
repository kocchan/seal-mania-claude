# 【7月第4週発売】グルミットめじるしアクセサリー

イギリス発の人気クレイアニメ『ウォレスとグルミット』から、めじるしアクセサリーが再登場します！ バンダイのガシャポンとして、2026年7月第4週に発売予定。おすわりポーズやハートを抱えたグルミット、フェザー・マッグロウ、ショーンなど、全6種がラインナップされます。

## 商品概要

「めじるしアクセサリー」は、傘やバッグ、水筒などの持ち物にちょこんと取り付けられる小さなチャームシリーズです。自分の持ち物の目印になるだけでなく、好きなキャラクターと一緒におでかけできる人気アイテムです。

今回の「ウォレスとグルミット めじるしアクセサリー」は再販商品で、2026年2月に発売した商品と同じラインナップ。愛犬グルミットのさまざまなポーズに加え、フェザー・マッグロウやショーンといった人気キャラクターも収録されています。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| グルミット | おすわりポーズの定番デザイン |
| グルミット（ハート） | ハートを抱えたキュートな一体 |
| グルミット（コック） | コック帽をかぶったユニークな姿 |
| フェザー・マッグロウA | 物語に登場する印象的なキャラクター |
| フェザー・マッグロウB | 表情違いのバリエーション |
| ショーン | 『ひつじのショーン』でもおなじみの人気者 |

全6種、グルミットのバリエーションの豊富さが魅力のラインナップです。

## ここがかわいい！見どころ

見どころは、愛らしい表情の愛犬グルミットのバリエーション豊かなポーズ。おすわりやハート、コック帽姿など、思わずクスッと笑ってしまうデザインが揃っています。フェザー・マッグロウやショーンといった、作品を彩る人気キャラクターも一緒に楽しめます。

傘の持ち手やバッグのファスナー、水筒などに付ければ、イギリス発のちょっぴりレトロで上質な世界観をおでかけ先にも連れていけます。クレイアニメ好き・犬好きどちらにもおすすめです。

## どこで回せる？買える？

全国のガシャポン自販機設置店（ガシャポンのデパート、ショッピングモール、家電量販店など）で取り扱われます。

確実に見つけたい人は、ガシャポン公式サイトの「設置店舗検索」で「ウォレスとグルミット」や「めじるしアクセサリー」と検索するのがおすすめです。再販商品のため、前回逃してしまった方も要チェックです。
