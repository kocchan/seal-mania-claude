# 【9月第3週発売】お文具といっしょ めじるしアクセサリー新作

絵文字みたいなまんまるフェイスがかわいい「お文具といっしょ」から、新作の「めじるしアクセサリーなのです」が登場します！ バンダイより2026年9月第3週発売予定で、お文具やプリンさん、猫さんなど全8種がラインナップ。ガシャポン初登場となる「耳」のパーツも見逃せません。

## 商品概要

「めじるしアクセサリー」は、カニカンとわっかパーツが付属したチャームタイプの人気シリーズで、傘やペンケース、バッグなどいろいろな持ち物に取り付けて“めじるし”として使えるアイテムです。今回は文房具メーカー・サンスター文具のキャラクター「お文具といっしょ」がテーマ。絵文字のような表情豊かなフェイス型デザインが特徴で、そのうち「ゼリーさん」はクリア素材を使用しています。さらに、ガシャポンでは初登場となる「耳」パーツもラインナップに加わり、コレクションの幅がぐっと広がりました。

## ラインナップ

| 種類 | ポイント |
|------|----------|
| お文具A | シリーズを象徴するキャラクターデザイン |
| お文具B | お文具Aとは異なる表情を楽しめる一種 |
| プリンさん | ぷるぷるとした質感を表現したデザイン |
| 名も無き者 | シリーズならではのユニークなキャラクター |
| 猫さん | にっこり笑顔がかわいい猫モチーフ |
| ゼリーさん | クリア素材を使用し透明感のある仕上がり |
| 子猫さん | 猫さんよりも小さくキュートなデザイン |
| 耳 | ガシャポンでは初登場となる新パーツ |

全8種の中でも、初登場の「耳」パーツと、クリア素材の「ゼリーさん」は特に注目のアイテムです。

## ここがかわいい！見どころ

一番の見どころは、絵文字のようなまんまるフェイスが持つ表情の豊かさ。ひとつひとつのキャラクターがどこかとぼけた雰囲気で、見ているだけでほっこりする愛らしさがあります。「ゼリーさん」はクリア素材ならではの透明感が魅力で、光に当たるとつるんとした質感が際立ちます。さらに今回初登場の「耳」パーツは、これまでのラインナップにはなかった新しい形。カニカン・わっかパーツ付きなので、ペンケースのファスナーや水筒、リュックなど毎日使うアイテムにちょこんと取り付けて、勉強や通学のお供にぴったりです。

## どこで回せる？買える？

全国のガシャポン専門コーナーやガシャポンのデパート、文具店・ショッピングモール内の設置機などで2026年9月第3週より順次発売予定です。初回発売後も複数回の出荷が予定されているので、欲しい種類が見つからなかった場合も再入荷のタイミングを狙うのがおすすめ。取り扱い店舗は、バンダイの公式ガシャポンサイトの設置店検索から調べられます。
