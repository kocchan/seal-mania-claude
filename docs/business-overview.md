# ビジネス概要

## サイトコンセプト

**ボンボンドロップシールの総合情報サイト**

小中学生の間で大流行中の「ボンボンドロップシール」に関する情報を発信し、ファンコミュニティの拠点となるサイトを目指す。

## ターゲット層

| セグメント | 説明 |
|-----------|------|
| 小中学生 | メインのコレクター層 |
| 保護者 | 子供のために購入する層 |
| コレクター | 大人のファン層 |

## 商品について

### ボンボンドロップシールとは

- **特徴**: ぷっくりした立体的な質感が特徴のシール
- **人気**: 小中学生の間で大流行中
- **希少性**: 一時期品薄で入手困難だった

## コンテンツ戦略

### メインコンテンツ: 目撃情報

販売店舗の発見報告を収集・発信する。

- どの店舗で売っていたか
- 在庫状況
- 価格情報
- 地域別の販売情報

### 将来的なコンテンツ

- 新商品・新シリーズ情報
- コレクション紹介
- 交換・トレード情報
- シールの保管方法・ケア情報
