# 記事ブラッシュアップフロー

Slack for Claudeで人間と会話しながら、下書き記事をブラッシュアップする。

## 概要

- **実行タイミング**: 人間がSlack通知を見たタイミング（随時）
- **実行環境**: Slack for Claude
- **入力**: `output/lottery-info/drafts/` の下書き（approved: false）
- **出力**: ブラッシュアップ済みの下書き（approved: true）

## 前提

collect-flowが完了し、Slack Webhookで「新しい下書きがあります」の通知を受け取っている状態。

## アーキテクチャ図

```
┌─────────────────────────────────────────────────────────┐
│  Step 1: 下書き確認                                     │
│                                                         │
│  人間: 「下書き見せて」                                  │
│  Claude: drafts/から下書きを取得して表示                 │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│  Step 2: 会話でブラッシュアップ                          │
│                                                         │
│  人間: 修正指示                                         │
│  Claude: 修正案を提示                                   │
│  （繰り返し）                                           │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│  Step 3: 承認                                           │
│                                                         │
│  人間: 「これでOK」                                      │
│  Claude: drafts/を更新、approved: true                  │
│  Claude: git commit & push                              │
└─────────────────────────────────────────────────────────┘
```

## Step 1: 下書き確認

Slack for Claudeに話しかけて下書きを確認する。

### 会話例

```
👤 人間:
下書き見せて

🤖 Claude:
新しい下書きが1件あります。

---

**【速報】ボンボンドロップシール「サンリオキャラクターズ moji」が5月15日発売！**

## ボンボンドロップシールに待望の新作登場！

ぷっくり立体的な質感が大人気の「ボンボンドロップシール」シリーズに、
サンリオキャラクターズの新デザイン「moji（モジ）」が登場することが発表されました！

（中略）

---

この内容でよろしいですか？修正したい箇所があればお知らせください。
```

## Step 2: 会話でブラッシュアップ

人間とClaudeが会話しながら記事をより良くしていく。

### 会話例1: 導入文の修正

```
👤 人間:
導入文をもっとキャッチーにして。
SNSの声も入れてほしい

🤖 Claude:
導入文を修正しました：

---

## ついに来た！サンリオ×ボンドロの最強コラボ第2弾！

「待ってました！」「可愛すぎて全種類集めたい！」

SNSで早くも話題沸騰中の新作が発表されました。

---

いかがでしょうか？
```

### 会話例2: キャラクター紹介の充実

```
👤 人間:
いいね！キャラ紹介をもっと詳しく書いて

🤖 Claude:
キャラクター紹介を充実させました：

---

### 全8種のラインナップ

1. **ハローキティ**
   1974年生まれの永遠のアイドル！赤いリボンがトレードマーク。

2. **シナモロール**
   シナモンロールみたいな耳が特徴。サンリオキャラクター大賞で連続1位！

3. **クロミ**
   マイメロディのライバル。黒いずきんにピンクのドクロがかっこかわいい！

---

いかがでしょうか？
```

### 会話例3: 情報の追加

```
👤 人間:
前回のサンリオコラボとの違いも書いて

🤖 Claude:
比較を追加しました：

---

## 前回コラボとの違い

| | 第1弾（2025年） | moji（今回） |
|---|---|---|
| デザイン | キャラクターイラスト | キャラクター名の文字 |
| テイスト | かわいい系 | ポップ・カジュアル系 |

---
```

## Step 3: 承認

ブラッシュアップが完了したら、人間が承認する。

### 会話例

```
👤 人間:
完璧！これでOK

🤖 Claude:
下書きを更新しました。

📝 ファイル: output/lottery-info/drafts/2026-05-01-sanrio-moji.md
✅ ステータス: approved: true
🔄 git push: 完了

この記事は次回のpost-flow（毎日9:00）でWordPressに投稿されます。
```

## フラグ更新

| 操作 | フラグ変更 |
|------|-----------|
| 「これでOK」 | approved: false → true |

## よく使う修正指示

| 指示 | 説明 |
|------|------|
| 「もっとキャッチーに」 | 導入文やタイトルをより魅力的に |
| 「詳しく書いて」 | 情報を充実させる |
| 「短くして」 | 冗長な部分を削る |
| 「〇〇を追加して」 | 特定の情報を追記 |
| 「比較表を入れて」 | 前作との違いなどを表形式で |
| 「SNSの声を入れて」 | X/Threadsの反応を引用 |

## Slack for Claudeの設定

### 必要な設定

1. Slack for ClaudeにGitHub連携を設定
2. リポジトリへのアクセス権限を付与

### できること

| 機能 | 可否 |
|------|------|
| drafts/の下書きを読む | ✅ |
| 下書きを修正・更新 | ✅ |
| approved: trueに変更 | ✅ |
| git commit & push | ✅ |

## 次のフロー

approved: true になった下書きは、**post-flow**（毎日9:00の定期実行）でWordPressに投稿される。
